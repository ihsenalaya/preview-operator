Prerequisites:
  - cert-manager is required when webhooks are enabled.
  - An ingress controller is required before preview URLs can route traffic.
  - OpenTelemetry Operator is optional and required only for app auto-instrumentation.

Create a preview environment:

  kubectl apply -f - <<EOF
  apiVersion: platform.company.io/v1alpha1
  kind: Cellenza
  metadata:
    name: pr-42
  spec:
    branch: feature/my-feature
    prNumber: 42
    image: myapp:latest
  EOF

Check status:

  kubectl get cellenza pr-42

Enable app auto-instrumentation by adding spec.telemetry to a Cellenza resource:

  telemetry:
    enabled: true
    serviceName: my-preview-app
    autoInstrumentation:
      language: python
      instrumentationRef: observability/python

Install ingress-nginx with Helm if your cluster does not already have an ingress controller:

  helm repo add ingress-nginx https://kubernetes.github.io/ingress-nginx
  helm repo update
  helm upgrade --install ingress-nginx ingress-nginx/ingress-nginx \
    --namespace ingress-nginx --create-namespace
